User APIs
    POST /api/v1/users → Create a user
    GET /api/v1/users → List all users
    POST /api/v1/login → Authenticate a user


Event APIs
    POST /api/v1/events → Create an event
    GET /api/v1/events → List all events
    GET /api/v1/events/:id/edit → Edit an event (not RESTful, consider using show)
    PUT/PATCH /api/v1/events/:id → Update an event
    DELETE /api/v1/events/:id → Delete an event


Transport APIs
    POST /api/v1/transports → Create a transport
    GET /api/v1/transports → List all transports
    PUT/PATCH /api/v1/transports/:id → Update a transport
    DELETE /api/v1/transports/:id → Delete a transport


Vendor APIs
    POST /api/v1/vendors → Create a vendor
    GET /api/v1/vendors → List all vendors
    PUT/PATCH /api/v1/vendors/:id → Update a vendor
    DELETE /api/v1/vendors/:id → Delete a vendor


Hotel & Room APIs
    POST /api/v1/hotels → Create a hotel
    GET /api/v1/hotels → List all hotels
    GET /api/v1/hotels/:id → Get details of a specific hotel
    PUT/PATCH /api/v1/hotels/:id → Update a hotel
    DELETE /api/v1/hotels/:id → Delete a hotel


Room APIs (Nested under hotels)
    POST /api/v1/hotels/:hotel_id/rooms → Create a room in a hotel
    GET /api/v1/hotels/:hotel_id/rooms → List all rooms in a hotel
    GET /api/v1/hotels/:hotel_id/rooms/:id → Get details of a specific room
    PUT/PATCH /api/v1/hotels/:hotel_id/rooms/:id → Update a room
    DELETE /api/v1/hotels/:hotel_id/rooms/:id → Delete a room


Group & Quest APIs
    POST /api/v1/groups → Create a group
    GET /api/v1/groups → List all groups
    GET /api/v1/groups/:id → Get details of a specific group
    PUT/PATCH /api/v1/groups/:id → Update a group
    DELETE /api/v1/groups/:id → Delete a group


Group Quest Management
    POST /api/v1/groups/:id/quests → Add quests to a group
    DELETE /api/v1/groups/:id/quests/:quest_id → Remove a quest from a group
    GET /api/v1/groups/:id/quests → List all quests in a group


Quest APIs
    POST /api/v1/quests → Create a quest

    GET /api/v1/quests/:id → Get details of a specific quest
    PUT/PATCH /api/v1/quests/:id → Update a quest
    DELETE /api/v1/quests/:id → Delete a quest


Quest Group Management
    GET /api/v1/quests/:id/groups → List all groups associated with a quest
