# API Documentation

## User APIs
- **POST /users** → Create a user
- **GET /users** → List all users
- **POST /login** → Authenticate a user

## Event APIs
- **POST /events** → Create an event
- **GET /events** → List all events
- **GET /events/:id/edit** → Edit an event (not RESTful, consider using show instead)
- **PUT/PATCH /events/:id** → Update an event
- **DELETE /events/:id** → Delete an event

## Transport APIs
- **POST /transports** → Create a transport
- **GET /transports** → List all transports
- **PUT/PATCH /transports/:id** → Update a transport
- **DELETE /transports/:id** → Delete a transport

## Vendor APIs
- **POST /vendors** → Create a vendor
- **GET /vendors** → List all vendors
- **PUT/PATCH /vendors/:id** → Update a vendor
- **DELETE /vendors/:id** → Delete a vendor

## Hotel & Room APIs
- **POST /hotels** → Create a hotel
- **GET /hotels** → List all hotels
- **GET /hotels/:id** → Get details of a specific hotel
- **PUT/PATCH /hotels/:id** → Update a hotel
- **DELETE /hotels/:id** → Delete a hotel

### Room APIs (Nested under hotels)
- **POST /hotels/:hotel_id/rooms** → Create a room in a hotel
- **GET /hotels/:hotel_id/rooms** → List all rooms in a hotel
- **GET /hotels/:hotel_id/rooms/:id** → Get details of a specific room
- **PUT/PATCH /hotels/:hotel_id/rooms/:id** → Update a room
- **DELETE /hotels/:hotel_id/rooms/:id** → Delete a room

## Group & Quest APIs
- **POST /groups** → Create a group
- **GET /groups** → List all groups
- **GET /groups/:id** → Get details of a specific group
- **PUT/PATCH /groups/:id** → Update a group
- **DELETE /groups/:id** → Delete a group

### Group Quest Management
- **POST /groups/:id/quests** → Add quests to a group
- **DELETE /groups/:id/quests/:quest_id** → Remove a quest from a group
- **GET /groups/:id/quests** → List all quests in a group

## Quest APIs
- **POST /quests** → Create a quest
- **GET /quests** → List all quests
- **GET /quests/:id** → Get details of a specific quest
- **PUT/PATCH /quests/:id** → Update a quest
- **DELETE /quests/:id** → Delete a quest

### Quest Group Management
- **GET /quests/:id/groups** → List all groups associated with a quest

## Restaurant & Dish APIs
- **POST /restaurants** → Create a restaurant
- **GET /restaurants** → List all restaurants
- **GET /restaurants/:id** → Get details of a specific restaurant
- **PUT/PATCH /restaurants/:id** → Update a restaurant
- **DELETE /restaurants/:id** → Delete a restaurant

### Dish APIs (Nested under restaurants)
- **POST /restaurants/:restaurant_id/dishes** → Create a dish in a restaurant
- **GET /restaurants/:restaurant_id/dishes** → List all dishes in a restaurant

## Dish & Ingredient APIs
- **GET /dishes/:id** → Get details of a specific dish
- **PUT/PATCH /dishes/:id** → Update a dish
- **DELETE /dishes/:id** → Delete a dish

### Ingredient APIs (Nested under dishes)
- **GET /dishes/:dish_id/ingredients** → List all ingredients of a dish

## Ingredient APIs
- **POST /ingredients** → Create an ingredient
- **GET /ingredients** → List all ingredients
- **GET /ingredients/:id** → Get details of a specific ingredient
- **PUT/PATCH /ingredients/:id** → Update an ingredient
- **DELETE /ingredients/:id** → Delete an ingredient
